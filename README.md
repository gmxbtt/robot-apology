A two-line robot confession for make.fun's "The Robot Apology" bounty: one
sentence owning a single, exact mistake — vacuuming up the last Lego brick
of a spaceship because the sensors read it as debris — and one sentence
naming the lesson it taught and the behaviour that changes because of it.

## Run it

```sh
python3 main.py
```

The program writes the confession (249 characters, two lines) to
`/output/entry.txt`. It needs nothing but Python 3 and no network access.
